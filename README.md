# AI / Портфолио — проект каталога (stage V0.5.1)

**03.11.2026 · Утверждённый дизайн и фирменный знак. Технический staging V0.3.1, не публичный релиз.**

Сайт создаётся по `TZ_AI_AGENTS_CATALOG_V1.0_2026-11-03.md`.

- Референс композиции: Framer AI Marketplace (без копирования шаблонов, медиа, кода).
- Собственная типографика Georgia + Inter fallback.
- Публичный целевой адрес: https://drozdov-dmitry.github.io/ai-portfolio/ (**публикация ещё не включена**).
- Astro 7.4.4, Node.js 22.12+, генерация статических страниц и клиентский поиск.
- В `src/data/demo-records.json` — 68 редакционных описаний, не публичный реестр авторизованных карточек. Приватные инструкции/промпты, транскрипты, локальные пути, настройки и данные учеников НЕ добавлены.
- Дизайн-макеты: главная, страница Метаархитектора, страницы 7 категорий и 404.

Запуск после установки Node 22:

```bash
npm install
npm run build
npm run dev
```

**Публикация:** требуются визуальное согласование, проверка содержимого и приватности, проверка ссылок и измерения качества. Ветка `develop` не подключена к GitHub Pages. Workflow только проверяет сборку и ничего не размещает.

**Известное ограничение:** локальная сборка Astro в редакционной среде не выполнялась из-за недоступности реестра npm. CI предназначен для воспроизводимой проверки в GitHub Actions. Lockfile будет добавлен при первой успешной установке зависимостей; он обязателен до релиза V1.0.
