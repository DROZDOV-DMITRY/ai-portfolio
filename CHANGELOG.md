# Changelog

## [0.7.1-stage] — 2026-11-03

- Вместо буквального совпадения внедрён поисковый движок по смысловым темам, словоформам и опечаткам на 68 продуктах
- Поиск понимает обычные задачи «сделать приказ», «аудио в текст», «профессия», «сайты», «видео»
- Результаты ранжируются по релевантности; сортировка, URL и фильтрация сохраняются
- Добавлены интерактивные быстрые запросы под основным поиском
- В GigaChat API не отправляются запросы и токены без защищённой серверной интеграции

## [0.7.0-stage] — 2026-11-03

- Каждый из 68 продуктов получил индивидуальный векторный знак, плюс 8 знаков направлений экосистемы.
- Полностью переработан блок направлений: выразительные визуальные карточки с геометрией, подсветкой, количеством продуктов и адаптивной сеткой 4/2.
- Публичное позиционирование: «ИИ-агенты и системы», каждый объект — ИИ-продукт.
- Технические ярлыки готовности, стадий, недостатка тестов и истории версий убраны с витрины и подробных страниц.
- Внутренний бэклог текущего состояния всех 68 продуктов сохранён отдельно на Google Диске.
- Существующая карточка ученической работы сохраняет авторство ученика. Медицинские и правовые границы применения остаются в публичных карточках.
- Редакционные исходные записи не получили автоматического публичного допуска.
