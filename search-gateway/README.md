# AI LAB — защищённый GigaChat Search Gateway

Текущая версия: подготовленный backend, НЕ развёрнут

Каталог останется на GitHub Pages; Node Function здесь должна развёртываться в Vercel с Root Directory = `search-gateway/` и маршрутом `POST /api/search`.

## Настройки сервера

- `GIGACHAT_AUTH_KEY` — GigaChat Authorization key; секрет только в защищённых переменных Vercel
- `GIGACHAT_SCOPE` — объём доступа, обычно `GIGACHAT_API_PERS`, иной только если подтверждён соответствующий тариф
- `TURNSTILE_SECRET_KEY` — секрет Cloudflare Turnstile, только на сервере
- `GIGACHAT_PUBLIC_ACCESS_APPROVED=true` — устанавливается только после проверки прав использования, бюджетных ограничений, антибот-защиты
- `GIGACHAT_MODEL=GigaChat-2` — необязательная модель

Публичная сборка сайта может использовать `PUBLIC_AI_SEARCH_ENDPOINT=https://<домен>/api/search` и `PUBLIC_TURNSTILE_SITE_KEY=<открытый ключ>` — это не секреты.

## Механизм

- GigaChat отбирает только существующие ID из публичного `/ai-portfolio/data/search-index.json`
- На сервере OAuth: https://ngw.devices.sberbank.ru:9443/api/v2/oauth
- Новый GigaChat API: https://api.giga.chat/v1/chat/completions
- Временный access token кешируется не дольше 24 минут
- Обязательная проверка Turnstile на сервере и точного домена `drozdov-dmitry.github.io`
- Пользовательский запрос максимум 180 символов, не более 5 рекомендаций, `max_tokens=600`
- При сбое модель не подменяется вымышленными результатами; клиент использует локальный поисковый движок
- Origin/CORS — дополнительная защита, НЕ авторизация и НЕ лимит расходов

## Ограничения

**Личные бесплатные токены GigaChat Freemium — только для некоммерческого использования**, см. https://developers.sber.ru/docs/ru/gigachat/tariffs/commercial . Публичная витрина продуктов может считаться коммерческим применением; проверить условия и нужный пакет ДО включения. Число 365 млн — предельная распределённая Freemium-квота, не подтверждение остатка аккаунта.

У публичного API дополнительно должны быть лимит расходов, rate-limit, наблюдение за расходом токенов и аварийное отключение. Turnstile только снижает автоматизированное злоупотребление, но не гарантирует ограничение расходов. Не размещать ключи в GitHub или HTML.
