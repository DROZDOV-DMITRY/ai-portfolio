# Публикационный барьер V0.5.0-stage

Дата: 03.11.2026.

Публичная сборка dist/ создаётся только из полностью утверждённых записей. Редакционный предпросмотр dist-preview/ может содержать 68 черновиков, поэтому его нельзя развёртывать на GitHub Pages.

Важно: исходники расположены в ПУБЛИЧНОМ репозитории и история Git доступна; описания уже доступны через GitHub. Это защита выходного сайта, не защита данных в Git.

Смена visibility и публикация требуют отдельной контентной и приватностной проверки. GitHub Pages не включён.
